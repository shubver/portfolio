04/How I work

Principles behind the systems

Fix the class of problem, not the instance.

A

Every failure becomes a rule

When something breaks in production, I record the decision that stops it happening again and add a test that enforces it.

  • 64 ADRs
  • 3,400+ offline tests
  • Cookbook runs in CI

B

Configuration over code

Durability, tracing, cost metering and access control belong to the platform. Agent authors declare what they need instead of rebuilding it for every agent.

  • Auto-retrying steps
  • Every token priced
  • Granted tools only

C

Evaluation decides

Features have to earn their place on held-out data, and models have to prove they track live behaviour. A good-looking metric is not enough to ship.

  • Dual-gate selection
  • VLM as judge
  • R² ≥ 0.95 gate

D

Privacy by construction

Customer identifiers never reach a model or stored state. LLMs reason over masked, generic feature types, not client or facility names.

  • De-identification airlock
  • Masked feature types
